Here are some things I’ve built:

Mference

A Swift and Metal engine that runs mixture-of-experts models larger than a Mac’s RAM, by keeping shared weights in memory and streaming the experts each token needs from SSD.

Qwen 3.6 (35B) decodes at 23.5–29.3 tok/s in about 1.45 GB, measured on a 24 GB M5.

Swift, Metal, custom .gturbo format, OpenAI-compatible server, Open WebUI. Source release for Apple Silicon; site at neelm0906.github.io/Mference.

Mauz

A desktop assistant for macOS and Windows: shake the mouse or press a shortcut, and it answers about whatever you’re pointing at, or hands the task to a coding agent.

Works with a Claude or ChatGPT subscription or an API key — no separate Mauz account — and can send work to Hermes, Claude Code, or Codex.

TypeScript, desktop app (macOS and Windows).

DeepSeek-V4 MTP restore

Put the Multi-Token Prediction head back into a popular W4A16-FP8 DeepSeek-V4-Flash quant — community checkpoints had dropped it — so vLLM speculative decoding actually speeds up decode.

On 2× RTX PRO 6000 Blackwell Max-Q: 52.85 → 85.52 tok/s at 524k context (+62%), and about 111 tok/s at 128k (+110%).

vLLM, GPTQ W4A16, FP8_BLOCK attention, Docker serve path. Work done at ACTi; Apache-2.0.

Community GGUF quants

Public llama.cpp quants of large MoE and multimodal models, with published quality and speculative-decoding numbers — including Agents-A1, Ornith 35B, Tencent Hy3, and NVIDIA Audex.

Agents-A1 IQ4_XS with a grafted MTP head measured 1.22× throughput versus the same quant without speculation, on a single RTX PRO 6000 Blackwell Max-Q.

llama.cpp GGUF, imatrix calibration, NVFP4, MTP sidecars. On Hugging Face as LordNeel.

OKC kernels

CUDA kernels for Muse Spark’s Open Kernel Challenge — a Muse-style decode stack covering attention, MoE, and projections — built from credited open-source bases and further original tuning.

Official decode-layer score 2.28× versus the reference.

CUDA, Python judge harness. Challenge closed 4 Nov 2026.

WindowsFinder

A Windows app and CLI that searches files by what’s in them, not just by name: keyword plus semantic hybrid search, with OCR and multilingual support.

On a 140-query eval (125 with an answer), hybrid search reached nDCG@10 0.888 and recall@10 0.960; median latency in that run was 175 ms.

Rust, Tauri, Svelte, tantivy BM25, EmbeddingGemma 2 via llama.cpp Vulkan.

paper2video

Turns an arXiv paper into a narrated, 3Blue1Brown-style explainer video using your own Claude Code or Codex subscription, then serves a local gallery. No GPU required.

A 5-tool allowlist cuts the fixed context of each headless agent call from about 41k tokens to about 5k.

Python, uv, Manim, Kokoro TTS, FastAPI, Claude Code / Codex.

Memory-Efficient Logits

I wrote a custom PyTorch autograd function that computes logits and cross-entropy in token chunks, and recomputes those chunk logits on the backward pass, so the full vocabulary-sized logit matrix never sits in memory at once.

Cuts peak memory 2.5–3.7× versus the standard path, at about 15% slower speed, in a forward-and-backward test with batch 4, sequence length 2,048, and vocabularies up to 200k.

Python, PyTorch, fp16.
